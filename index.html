🎨 Color Guide:

  • Gold: Pivot element (the partition benchmark)
  • Cyan: Pointer i (boundary for elements ≤ pivot)
  • Purple: Pointer j (current scanner)
  • Coral: Elements actively swapping
  • Green: Elements in their final locked sorted position
